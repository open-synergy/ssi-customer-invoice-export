=====================================================
Customer Invoice Export + Operating Unit Integration
=====================================================

This module integrates Operating Unit support into the Customer Invoice Export
module. A Customer Invoice Export document can be scoped to a specific
operating unit; when set, the **Populate** button only selects customer
invoices and allowed journals belonging to that operating unit.
